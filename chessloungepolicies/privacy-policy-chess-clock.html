Introduction

Chess 960 Generator is part of the Chess Lounge Series, a collection of chess applications developed under The Lounge. The application is a simple chess utility tool designed to generate random, valid Chess960 (Fischer Random Chess) starting positions.

Chess 960 Generator helps chess players create unique starting positions for practice, analysis, and over-the-board games while maintaining a simple, private, and offline-first experience.

Information Collection

Chess 960 Generator does not collect, store, transmit, or share any personal information from users.

The application does not require user registration, account creation, login, or any personal information input. All Chess960 positions are generated locally on your device.

Device Permissions

Chess 960 Generator does not request or access sensitive device features such as:

  • Camera
  • Microphone
  • Location Services
  • Contacts
  • Photos or Media Files
  • Personal File Storage

The application does not capture images, record audio, collect location data, or access private user information. It only performs the necessary functions required to generate Chess960 positions.

Internet Usage

Chess 960 Generator is designed to operate completely offline. An internet connection is not required to generate Chess960 positions.

The application does not transmit user activity, generated positions, device information, or any other personal data over the internet.

Third-Party Services

Chess 960 Generator does not use advertising networks, analytics platforms, tracking tools, or third-party services that collect user information.

Children's Privacy

Chess 960 Generator does not collect personal information and is suitable for users of all ages, including children.

Data Security

Since Chess 960 Generator does not collect or store personal data, there is no personal information retained by the application that could be accessed, shared, or compromised.
